# ADR-0005: 機密らしい内容を記録しない

- Status: Accepted
- Date: 2026-10-16

## Context

- クリップボードの履歴は、パスワード、API トークン、秘密鍵がうっかり残る典型的な場所になる。
- パスワードマネージャーの多くは、コピーしたデータに [nspasteboard.org](http://nspasteboard.org/) で決められた印（`org.nspasteboard.ConcealedType` など）を付けて、「記録しないでほしい」と伝えている。
- 暗号化して保存しても、パネルに表示すれば画面の盗み見や画面共有で漏れる。記録しないのが一番安全。

## Decision

次の3段階で判定し、**どれかに当てはまったら記録しない。** 判断に迷うものは記録しない側に倒す。

1. **クリップボードの印**: ConcealedType / TransientType / AutoGeneratedType などが付いている
2. **コピー元のアプリ**: 除外リストにあるアプリが最前面にあるときにコピーされた
3. **内容のパターン**: トークンや秘密鍵らしい文字列が含まれる

細かい条件は [filtering.md](../specs/filtering.md) で決める。

## Consequences

- パスワードマネージャーからのコピーが履歴に残らない。
- パターンを広くすると、普通の文字列まで記録されないことがある。その場合は、記録されなくても困らない、と割り切る。
- パターンに当てはまらない機密文字列は記録される。完全には防げないので、メニューバーから **記録の一時停止** と **履歴の消去** ができるようにして補う。
- 記録しなかったときも、内容はログに出さない。
