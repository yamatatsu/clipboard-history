# ADR-0006: スニペットを平文の JSON ファイルで管理する

- Status: Accepted
- Date: 2026-10-16

## Context

- Clipy と同じく、フォルダ分けした定型文を呼び出して貼り付けたい。
- Clipy にはスニペットを編集する専用の画面があるが、作ると UI のコード量が大きく増える。
- スニペットは自分で書く定型文で、機密情報を入れる場所ではない。
- 暗号化すると、編集するには専用の画面が必要になる（ファイルを直接は編集できない）。

## Decision

- スニペットは `~/Library/Application Support/SafeClipy/snippets.json` に **平文** で置く（パーミッションは 0600）。
- 編集は、メニューの「スニペットを編集…」で、このファイルを既定のエディタで開いて行う。アプリには編集画面を作らない。
- ファイルの変更を検知して自動で読み込み直す。手動で読み込み直すメニューも用意する。
- ファイルの形式は [snippets.md](../specs/snippets.md) で決める。

## Consequences

- UI が小さく済み、好きなエディタで編集できて、git などでの管理もしやすい。
- **機密情報をスニペットに入れてはいけない**（README に明記する）。
- 将来、暗号化やアプリ内での編集が必要になったら、新しい ADR で見直す。
