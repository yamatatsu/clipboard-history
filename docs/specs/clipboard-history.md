# クリップボード履歴

## 監視

- `NSPasteboard.general.changeCount` を **0.5秒ごと** に確認する（macOS にはクリップボードの変更を通知する仕組みがないため）。
- `changeCount` が変わっていたら、次の順に処理する。
  1. 自分が書き込んだもの（独自の印 `local.clipboardhistory.marker` が付いている）なら無視する
  2. 記録の一時停止中なら無視する
  3. `NSPasteboard.PasteboardType.string` を読む。テキストがなければ無視する（画像やファイルは扱わない）
  4. [filtering.md](filtering.md) の判定で記録しないと決まったら無視する
  5. 履歴に追加する

## 記録する項目

```swift
struct HistoryItem: Codable, Identifiable {
    let id: UUID
    var text: String
    var copiedAt: Date      // 最後にコピーまたは貼り付けた日時
}
```

コピー元のアプリ名などは記録しない（必要最小限にする）。

## 追加のルール

- 空文字や、空白・改行だけのものは記録しない。
- **1MB を超えるテキスト** は記録しない。
- 同じテキストがすでにあれば新しく足さず、そのテキストを **先頭に移して** `copiedAt` を更新する。
- 新しいものほど先頭にする。
- 上限の **30件** を超えたら、末尾（一番古いもの）から消す。

## 保存期間

- `copiedAt` から **7日** 経ったものを消す。
- 判定のタイミングは、起動時、履歴を追加したとき、1時間ごとのタイマー。

## 貼り付けたとき

- パネルで選んで貼り付けた項目は、先頭に移して `copiedAt` を更新する（Clipy と同じ）。

## 消去

- メニューの「履歴を消去」で、メモリ上の履歴を空にしてすぐ保存する（暗号化された空の履歴で上書きする）。

## 保存のタイミング

- 履歴が変わってから **1秒後** にまとめて保存する（連続してコピーしたときに書き込みが続かないようにする）。
- アプリを終了するときにも保存する。
- 保存の方法は [storage-and-encryption.md](storage-and-encryption.md) を参照。
