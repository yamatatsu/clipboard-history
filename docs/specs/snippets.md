# スニペット

方針は [ADR-0006](../ADR/0006-snippets-plaintext-json.md) を参照。

## ファイル

- パス: `~/Library/Application Support/SafeClipy/snippets.json`（パーミッション 0600）
- ファイルがなければ、初回の起動時にサンプル入りで作る。
- **平文** なので、機密情報は入れない。

## 形式

```json
{
  "version": 1,
  "folders": [
    {
      "title": "メール",
      "snippets": [
        { "title": "お礼", "content": "お世話になっております。\n..." },
        { "title": "署名", "content": "山本\n..." }
      ]
    }
  ]
}
```

- `folders` と `snippets` は、ファイルに書いた順に表示する。
- `title` は表示用。`content` が貼り付ける本文。
- `title` が空なら、`content` の1行目を表示に使う。

## 読み込み

- 起動時に読み込む。
- ファイルの変更を `DispatchSource.makeFileSystemObjectSource` で監視し、変わったら読み込み直す。エディタが保存のたびにファイルを置き換える場合にも対応するため、監視は張り直す。
- メニューの「スニペットを再読み込み」でも読み込み直せる。
- **形式が正しくない（JSON として読めない）場合** は、前に読み込めた内容をそのまま使い続け、エラーの場所（行など）を通知する。

## 編集

- メニューの「スニペットを編集…」で、`NSWorkspace.shared.open` を使ってファイルを既定のアプリで開く。
- アプリには編集画面を作らない。

## 貼り付け

- スニペットのパネル（`⌘⇧B`）で選ぶと、履歴と同じ流れで貼り付ける（[ui-and-paste.md](ui-and-paste.md)）。
- スニペットを貼り付けても、その本文は **履歴に入れない**（自分で書き込んだ印が付くので、監視の段階で無視される）。
