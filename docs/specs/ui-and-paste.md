# ホットキー、パネル、貼り付け、メニューバー

## アプリの形

- `Info.plist` に `LSUIElement = true` を指定し、Dock に出さずメニューバーにだけ常駐させる。
- メニューバーのアイコンは SF Symbols の `doc.on.clipboard`。記録の一時停止中は `pause.circle` にする。

## ホットキー

| ホットキー | 動作 |
|---|---|
| `⌘⇧V` | 履歴のパネルを開く |
| `⌘⇧B` | スニペットのパネルを開く |

- Carbon の `RegisterEventHotKey` で登録する（アクセシビリティの許可は不要）。
- 登録に失敗したとき（他のアプリが同じキーを使っているなど）は、そのことを通知する。
- `⌘⇧V` は一部のアプリで「スタイルなしで貼り付け」に割り当てられているが、Clipy と同じなのでそのまま使う。

## パネル

- `NSPanel` を使い、`.nonactivatingPanel` にする。こうすると、パネルを開いても元のアプリのフォーカスが外れず、そのまま貼り付けられる。
- マウスカーソルの近くに出す。画面からはみ出す場合は、画面の中に収まるようにずらす。
- 上に検索欄、その下に一覧を並べる。

### 履歴のパネル

- 1行に1項目。テキストの1行目を最大60文字まで表示し、それより長ければ `…` を付ける。改行やタブは見える記号に置き換える。
- 先頭の9件には `1`〜`9` の番号を付ける。
- 項目の上にマウスを置くか選ぶと、全文（最大500文字まで）をツールチップで見せる。

### スニペットのパネル

- フォルダごとに見出しを付けて、スニペットを並べる。
- 検索欄の文字で、フォルダ名、`title`、`content` を絞り込む。

### キー操作

| キー | 動作 |
|---|---|
| 文字を入力 | 絞り込み（大文字と小文字を区別しない部分一致） |
| `↑` `↓` | 選択を動かす |
| `1`〜`9` | 検索欄が空のときだけ、その番号の項目に決める |
| `⏎` / クリック | 決める |
| `esc` / パネルの外をクリック | 閉じる |

## 貼り付け（Clipy と同じ動作）

1. パネルを閉じる
2. 選んだテキストをクリップボードに書き込む。このとき `string` 型に加えて、自分が書き込んだ印 `local.clipboardhistory.marker` も付ける
3. 少し待つ（約50ms。元のアプリにフォーカスが戻るのを待つ）
4. `CGEvent` で `⌘V` を送る
5. 貼り付けたのが履歴の項目なら、その項目を先頭に移す

- クリップボードは、貼り付けた内容のまま残す（Clipy と同じ。前の内容には戻さない）。
- **アクセシビリティの許可がない場合**（`AXIsProcessTrusted()` が false）は、4 を飛ばしてクリップボードに入れるだけにし、許可が必要なことを通知する。
- 起動時に許可がなければ、`AXIsProcessTrustedWithOptions` で許可を求めるダイアログを1回だけ出す。

## メニューバーのメニュー

```
ClipboardHistory
─────────────
履歴を開く            ⌘⇧V
スニペットを開く      ⌘⇧B
─────────────
記録を一時停止 / 再開
履歴を消去…
─────────────
スニペットを編集…
スニペットを再読み込み
─────────────
ログイン時に起動      ✓
─────────────
ClipboardHistory を終了
```

- 「履歴を消去…」は、消してよいか確認してから消す。
- 一時停止の状態は再起動すると元に戻る（再起動したら必ず記録を再開する）。
- 「ログイン時に起動」は `SMAppService.mainApp` の登録と解除で切り替える。

## 通知

- 使うのは `UserNotifications` か、メニューバーのアイコン付近への簡単な表示（実装するときに決める）。
- 通知にもクリップボードの内容は含めない。
