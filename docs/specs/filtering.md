# 記録しない内容の判定

方針は [ADR-0005](../ADR/0005-sensitive-content-filtering.md) を参照。上から順に判定し、どれかに当てはまったら記録しない。

## 1. クリップボードの印

`NSPasteboard.general.types` に次のどれかが含まれていたら記録しない。

| 印 | 意味 |
|---|---|
| `org.nspasteboard.ConcealedType` | パスワードなどの機密 |
| `org.nspasteboard.TransientType` | 一時的なデータ |
| `org.nspasteboard.AutoGeneratedType` | 自動で生成されたデータ |
| `com.agilebits.onepassword` | 1Password の独自の印 |
| `com.typeit4me.clipping` | TypeIt4Me の独自の印 |
| `de.petermaurer.TransientPasteboardType` | 古い一時データの印 |
| `Pasteboard generator type` | 他のクリップボードツールの印 |

## 2. コピー元のアプリ

`changeCount` の変化に気づいた時点で、`NSWorkspace.shared.frontmostApplication` の bundle ID が次のどれかなら記録しない。

| bundle ID | アプリ |
|---|---|
| `com.1password.1password` | 1Password 8 |
| `com.agilebits.onepassword7` | 1Password 7 |
| `com.bitwarden.desktop` | Bitwarden |
| `com.apple.keychainaccess` | キーチェーンアクセス |
| `com.apple.Passwords` | パスワード（macOS 15 以降） |

- 一覧はコードに定数で持つ。足したくなったら、コードを変えてこの表も更新する。
- 最前面のアプリはポーリングの間隔の分だけずれることがある。主な防御は1の「印」で、こちらは補助と考える。

## 3. 内容のパターン

テキストのどこかに、次の正規表現のどれかが当てはまったら記録しない。

| 種類 | パターン（概要） |
|---|---|
| 秘密鍵 | `-----BEGIN [A-Z ]*PRIVATE KEY-----` |
| GitHub トークン | `gh[pousr]_[A-Za-z0-9]{36,}`、`github_pat_[A-Za-z0-9_]{22,}` |
| AWS アクセスキー | `\b(AKIA\|ASIA)[0-9A-Z]{16}\b` |
| Slack トークン | `xox[abprs]-[A-Za-z0-9-]{10,}` |
| Anthropic / OpenAI の API キー | `sk-ant-[A-Za-z0-9_-]{20,}`、`sk-[A-Za-z0-9_-]{20,}` |
| Google の API キー | `AIza[0-9A-Za-z_-]{35}` |
| JWT | `eyJ[A-Za-z0-9_-]{10,}\.eyJ[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}` |

- パターンはコードに定数で持ち、単体テストを書く（当てはまるべき例と、当てはまってはいけない例の両方）。
- 判定は記録する前に1回だけ行う。

## 記録しなかったとき

- 何も保存しない。ログには、どの段階で記録しなかったか（例: `skipped: marker`）だけを出し、**内容は出さない**。
- 利用者への通知はしない（コピーするたびに通知が出るとうるさいため）。
